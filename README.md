# CloudThrift Landing Page & Design System

Open-source landing page and design tokens for **CloudThrift** — Read-only AWS Cost Audits & FinOps visibility.

## 🚀 Live Site
- **GitHub Pages**: [https://mahadikabhijeet.github.io/cloudthrift/](https://mahadikabhijeet.github.io/cloudthrift/)

## 📄 Structure
- `index.html`: Main CloudThrift landing page with interactive ROI calculator, audit features, & security guarantee.
- `form.html`: Lead capture form for free audit requests.
- `assets/`: SVGs, logos, and brand icons.
- `design-system/`: Design tokens, colors, typography, and reusable UI components.

## 💻 Local Development
Simply serve this directory with any static server:
```bash
python3 -m http.server 8000
```
Open `http://localhost:8000` in your browser.
