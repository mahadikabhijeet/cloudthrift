AWS fix pack: export in about a minute

  1. Open the AWS console, go to Billing and Cost Management, then Cost Explorer.
  2. Set the date range to the last 3 months and granularity to Monthly.
  3. Group by Service. Click Download CSV.
  4. Change Group by to Usage type. Download CSV again.
  5. Optional but helpful: tell us your main regions and which accounts are production.

AI bill fix pack: what to send

  1. OpenAI or Anthropic: open the usage page in the console and export the last 1 to 3 months as CSV.
  2. Bedrock: in AWS Cost Explorer, filter Service to Bedrock, group by Usage type, download CSV.
  3. 5 to 10 sample requests (prompt and settings) with any private data removed, and one line on what each job does.

Never send passwords, access keys or API keys. Your fix pack arrives within 48 hours of receiving complete data.
